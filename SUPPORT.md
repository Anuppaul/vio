# Support

VIO is an independent open-source project maintained by **Anuppaul**.

- **Bug or regression?** Open a [bug report](https://github.com/Anuppaul/vio/issues/new/choose). Include the affected module, browser/Android version and exact reproduction.
- **Improvement or accessibility request?** Open a [feature request](https://github.com/Anuppaul/vio/issues/new/choose).
- **Build trouble?** Provide Node/Java/Android SDK/Gradle versions and the first failing compiler task; do not post secrets or signing keys.
- **Security issue?** Read [SECURITY.md](SECURITY.md); avoid public exploit details.
- **Permission/licensing question about audio?** Read [docs/ASSET_LICENSING.md](docs/ASSET_LICENSING.md) before redistributing recordings.

VIO is maintained on a best-effort basis. No commercial support commitment or response time is implied.
