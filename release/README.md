# VIO Android packages

The **Build Android APK** GitHub Actions workflow builds Capacitor 8.5.2 from this repository, verifies the APK signature, tests the bundled web UI, then commits the actual APK to this folder. This README is not a substitute for a built package: check `build-debug.json` and the adjacent `.apk.sha256` after the workflow succeeds.

## Current package naming

- `vio-1.0.0-debug.apk`: installable development/test APK, **not a Play Store production release**.
- `vio-1.0.0-debug.apk.sha256`: checksum for the exact binary.
- `build-debug.json`: source commit, package name, version, size and signing type.
- `test-results/`: browser smoke-test results and screenshots, not a physical-device certification.

Download the APK using GitHub's **Download raw file** action. Android may request permission to install from the browser/file manager. This APK supports Android 7.0/API 24+ with an updated Android System WebView/Chrome (111+). Microphone permission is requested only when a microphone feature is started. All final audio assets are bundled; no Vercel server is required for the native app.

The test APK is signed with a development key generated by the build environment. It is not a production identity. A later test build with a different development key may require uninstall/reinstall (which removes app-local settings). Keep a private, stable release keystore for production updates; never commit it here.

## Local build

Node 22+, JDK 21, Android SDK platform 36 and Build Tools 36.0.0 are required. Set `ANDROID_HOME`, install dependencies with `npm ci` (or `npm install` before the first lockfile exists), then run:

```sh
npm run android:apk
```

`npm run build` remains the hosted web/PWA build. `npm run android:apk` creates a separate static export, runs Capacitor sync, builds Android, verifies its signature, and copies the result into this folder. Generated native project sources are checked in after the first successful workflow; build outputs, copied web assets, local SDK paths and keystores are ignored.

For a privately signed release, set `VIO_KEYSTORE_PATH`, `VIO_KEYSTORE_PASSWORD`, `VIO_KEY_ALIAS`, `VIO_KEY_PASSWORD`, and a monotonically increasing `VIO_VERSION_CODE` in your local environment, then run:

```sh
node scripts/build-apk.mjs --release
```

Do not paste private keys or passwords into source files or chat. The release command refuses to build without all signing inputs.

## Acceptance boundary

CI verifies hosted-web compilation, native compilation, Android lint, APK signing, local page navigation, required bundled audio, and synthetic microphone pitch detection in desktop Chromium. Physical Android microphone accuracy, permission denial/regrant, interruptions, Bluetooth audio and airplane-mode use should still be checked on an actual phone. No background/lock-screen audio service is included. The Sound Tuner's raw Pitchy detector is unchanged.
