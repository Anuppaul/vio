TANPURA AUDIO ASSETS

This directory contains the existing 24 Sa–Pa and Sa–Ma MP3 playback files,
with all twelve keys. The files are required for the current VIO Tanpura
and Android offline audio experience.

The recordings were captured from an external source. Their redistribution
rights have not been established by the project's MIT source-code license.
Original capture URLs and source details remain preserved in Git history at
commit b3b0d5ea31b93b934a416996add623540c181a89 for a future rights audit.

The app reads the MP3 files by their existing filenames. Do not remove or
rename those files without adjusting the playback code and verifying the APK.
